# Cambio Valute

Convertitore istantaneo tra più valute (predefinite: EUR, USD, KHR, THB, AUD, IDR — modificabili dall'app).
Scrivi un importo in una riga e tutte le altre si convertono.

- App: https://valeriowork360.github.io/Cambio-valuta/
- I tassi (`rates.json`) sono aggiornati da una GitHub Action alle 07:47 e 22:47 ora di Phnom Penh
  (fonti: open.er-api.com + tassi di riferimento BCE via frankfurter.dev).
- Installabile sulla schermata Home (PWA), funziona anche offline con gli ultimi tassi scaricati.
